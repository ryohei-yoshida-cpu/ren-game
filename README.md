# わるいワニをやっつけろ『ひらがなまてまて』

4さいごろの こどもが、おひめさまを さらった わるい ワニを ゆびで おいかけながら ひらがなを おぼえる ゲームです。

## あそびかた

### おはなし
ありの おひめさまが、サングラスを かけた わるい ワニに さらわれた！ ワニは こぶんの おしろへ つぎつぎ にげこむ。
「あ」から じゅんばんに なかまを ふやしながら、おいかけよう。

1. キャラ（「あ」なら 🐜 あり、「い」なら 🐶 いぬ）を **タップ** すると、「い、い、いぬの い♪」と うたう
2. おしろから **ワニが おひめさまを つれて とびだし、かきじゅんどおりに ひらがなの かたちを にげていく**（おてほん）
3. ひらがなの **さきっぽに キャラが あらわれる**。ゆびで なぞると キャラが ワニを おいかけ、そのまま ひらがなが かける。かきおわると ワニは おしろへ にげかえる
4. かいている とちゅうで **「⚡ へんしん！」ボタン** を おすと、ヒーローに へんしん
5. **3こめ と 5こめ** は おしろから **わるもの** が でてくる。ぶつかりあいっこを **れんだ** で おしかえし、ヒーローの **ひっさつわざ** で やっつける（5こめの てきは 3こめより つよい）
6. 5こめの てきは **おしろへ ふっとんで、おしろが こわれる**。ワニは「まだまだ やられないもんねー！ つぎの おしろへ にげるもんねー！」と まけおしみ（まいかい ちがう セリフ）を いって、つぎの おしろへ にげていく
7. つぎの キャラに「なかまに なって たすけてくれ！」「わかった！」で こうたい
8. 1つの だんを クリアするたびに **「きょうは ここまで？」** と きく
9. おしろは だん（5もじ）ごとに かわり、**だんだん おおきく** なる。さいごの「わ」の だんは **ワニの おしろ** 🏯。こわすと おしろが だいばくはつ！ いちばん つよい ワニの ボスを れんだで たおして、おひめさまを きゅうしゅつ。ほっぺに チュー♡

- や・わ の だん（3もじ）は 3こめが つよい てきに なります
- オープニングは はじめて あそぶ ときに ながれます。タイトルの「📖 おはなし」で もういちど みられます

### モード
- **じゅんばん**: あ→い→う→え→お の じゅん
- **ランダム**: その だんの なかで じゅんばんが バラバラ

### ほぞん
- すすんだ だん・メダル・モード（じゅんばん／ランダム）は ブラウザ（localStorage）に ほぞんされます
- タイトルの「さいしょから（おとなよう）」で リセットできます

## うごかしかた（Android）

アプリストアからは ダウンロードしません。**インターネット上に おいた ページを Chrome で ひらいて、ホームがめんに ついか** すると アプリとして つかえます（PWA）。
いちど ひらけば **オフラインでも あそべます**。

### 1. ページを こうかいする（さいしょに 1かいだけ・パソコン推奨）

このリポジトリは **プライベート** なので、むりょうの GitHub Pages を つかうには **パブリックに する** ひつようが あります（ひみつの じょうほうは ふくまれていません）。

1. GitHub の リポジトリ → **Settings → General** の いちばん した「Danger Zone」→ **Change visibility → Public**
2. **Settings → Pages** → Source: `Deploy from a branch` → Branch: `main`（または この ブランチ）/ `/(root)` → **Save**
3. 1〜2ふん まつと `https://ryohei-yoshida-cpu.github.io/ren-game/` で ひらけるように なります

> プライベートの まま にしたい ばあいは、[Cloudflare Pages](https://pages.cloudflare.com/) や [Netlify](https://www.netlify.com/) に GitHub を つなげば むりょうで こうかいできます（ビルドコマンドなし・こうかいフォルダは ルート）。

### 2. Android に いれる

1. Android の **Chrome** で うえの URL を ひらく
2. タイトルがめんの **「📲 ホームがめんに ついか」** ボタンを おす
   （でない ときは Chrome の **︙メニュー → 「ホーム画面に追加」/「アプリをインストール」**）
3. ホームがめんの アイコンから ひらくと、ぜんがめんで あそべます

### 🎙 じぶんたちの こえに する（こえの スタジオ）
タイトルの **「🎙 こえ」** から、ゲームの ぜんぶの セリフを じぶんたちの こえに とりかえられます。

- セリフは やく（ナレーション・なかま・おひめさま・ワニ・わるもの）ごとに ならんでいます。さがす ことも できます
- **●** で ろくおん → よみおわったら **■**。まえと うしろの しずかな ところは じどうで けずります。すぐ ゲームの こえが かわります
- **▶** で きく、**↺** で もとの こえに もどす。「とった こえを つかう」の チェックを はずすと、いちじてきに もとの こえに もどります
- とった こえは その スマホの なかに ほぞんされます（インターネットには おくられません）

#### LINE で ともだちに たのむ
1. スタジオで たのみたい セリフに ✓ を つけて **「📨 えらんだ セリフを LINEで たのむ」** → LINE を えらんで おくる
2. ともだちは リンクを ひらく（LINE の なかで マイクが つかえない ときは、みぎうえの メニューから「ブラウザで ひらく」）。たのまれた セリフだけ でるので、ろくおんして **「✅ できた！ おくりかえす」** → LINE を えらんで おくりかえす（「こえパック_なまえ_◯こ.pdf」という ファイルが とどく）
3. LINE で とどいた PDF を ひらいて **ほぞん**（ダウンロード）し、スタジオの **「📥 こえを よみこむ」** で その PDF を えらぶと、ともだちの こえに かわります

> こえパックは PDF です。ひらくと せつめいの ページが みえて、こえの データは なかに はいっています。
> LINE は メッセージと ファイルを いっしょに おくると ファイルを おとして しまうので、こえパックは ファイルだけで おくります。

じぶんで とった こえも **「📤 とった こえを おくる」** で こえパックに できるので、べつの スマホへの おひっこしや バックアップにも つかえます。

#### セリフを かえた とき（こえの つくりなおし）
`js/game.js` の `Sound.say('セリフ', { who: '...' })` や `js/data.js` を かえたら、こえを つくりなおします（パソコン・Linux）。
こえの ファイルが ない セリフは、ブラウザの よみあげで しゃべります。

```sh
node tools/voices/lines.mjs     # セリフを あつめる → tools/voices/lines.json
VV_DIR=/path/to/voicevox python tools/voices/gen.py   # ない ぶんだけ つくる → audio/voice/
```

`VV_DIR` には VOICEVOX CORE（0.16）の つぎの ものを おきます（GitHub の Releases から ダウンロード）。
python には `voicevox_core-0.16.x-...whl` を pip で いれておきます。ffmpeg も つかいます。
- `voicevox_onnxruntime-linux-x64-1.17.3/`（VOICEVOX/onnxruntime-builder）
- `open_jtalk_dic_utf_8-1.11/`（r9y9/open_jtalk）
- `vvms/0.vvm`, `vvms/4.vvm`, `vvms/9.vvm`（VOICEVOX/voicevox_vvm）

## ☁️ データを ほかの スマホと きょうゆう する

タイトルの **「☁️ きょうゆう」** で ID を いれると、すすみぐあい・メダル・とった こえ が ウェブ（Firebase）に ほぞんされます。
ほかの スマホで おなじ ID を いれると、おなじ データで あそべます。

- はじめての スマホ: 「ID を つくる」→「つなぐ」（ID は メモして おく）
- ほかの スマホ: その ID を いれて「つなぐ」
- あそぶ・ろくおんする・アプリを ひらく たびに じどうで どうきします（オフラインの ときは つながったら）
- すすみぐあいは **たしざん** で まざります（クリアした だん・メダルの かいすうは おおきい ほう）。どの スマホで あそんでも へりません
- 「さいしょから」に すると、ほかの スマホも さいしょからに なります
- ⚠️ ID を しっている ひとは だれでも データを みたり かえたり できます。かぞく だけの ひみつに してください

### はじめに 1かいだけ: Firebase の セットアップ（おとなよう・むりょう）
1. <https://console.firebase.google.com> を Google アカウントで ひらき、**「プロジェクトを作成」**（なまえは なんでも OK。Google アナリティクスは オフで OK）
2. ひだりの メニュー **「構築」→「Firestore Database」→「データベースの作成」** → ロケーションは `asia-northeast1 (Tokyo)` → **「本番環境モード」** で つくる
3. Firestore の **「ルール」** タブを ひらき、この リポジトリの [`firestore.rules`](firestore.rules) の なかみを まるごと はりつけて **「公開」**
4. ⚙️ **「プロジェクトの設定」** → 「マイアプリ」の **`</>`（ウェブ）** → アプリの ニックネームを いれて 登録 → でてくる `firebaseConfig` の **`apiKey`** と **`projectId`** を コピー
5. [`js/cloud-config.js`](js/cloud-config.js) に はりつける（または Claude に おくって いれて もらう）

```js
window.CLOUD_CONFIG = {
  apiKey: 'AIza....',
  projectId: 'hiragana-matemate-xxxx',
};
```

`apiKey` は ウェブアプリに いれて つかう ための もので、ひみつの パスワードでは ありません（まもりは ルールで します）。
むりょうの はんい（1にち 5まん かい よみこみ・2まん かい かきこみ、1GB）で じゅうぶん たります。
